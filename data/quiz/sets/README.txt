Optional hand-written questions.

Drop a .json file here shaped like:

[
 { "word": "abate",
   "kicker": "Closest in meaning",
   "cue": "abate",
   "answer": "subside",
   "options": ["subside", "provoke", "endorse", "linger"] }
]

Then add the filename to "sets" in ../config.json. The app merges these
with the generated questions. Nothing here is required.
